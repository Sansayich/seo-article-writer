# SEO Article Writer — скилл для Claude Code

Автоматизированное написание SEO-статей, которые попадают в ТОП Яндекса и Google. Полный пайплайн: от сбора семантики до публикации с картинками.

## Что делает этот скилл

Скилл берёт тему статьи и проводит её через 10-этапный пайплайн, на выходе — готовая статья с:

- Семантическим ядром из Яндекс Wordstat (частотность, LSI, сезонность)
- Анализом топ-5 конкурентов в поисковой выдаче (структура, гэпы, интенты)
- Проверенной фактурой (цены, статистика — только из первоисточников)
- AI-обложкой с заголовком на русском языке
- Скриншотами каждого упомянутого сервиса
- AI-иллюстрациями к каждому разделу
- On-page оптимизацией (meta, Schema.org, перелинковка)
- Автопубликацией в WordPress / Prisma Blog / HTML-файл

## Требования

- **Claude Code** (CLI от Anthropic) с подключённым скиллом
- **Node.js** 18+ (для Playwright — скриншоты сайтов)
- **API-ключ ApiYi** — для генерации изображений (Nano Banana 2)
- **Сервер с SSH** — для хранения изображений и серверных скриншотов (или альтернатива: S3, R2, локальный сервер)
- **Wordstat MCP** — MCP-сервер для работы с Яндекс Wordstat (опционально, но рекомендуется)

## Быстрый старт

**Шаг 1: Установи скилл**

```bash
# Скопируй папку скилла в директорию Claude Code
cp -r seo-article-writer-public ~/.claude/skills/seo-article-writer

# Создай конфиг из примера
cp ~/.claude/skills/seo-article-writer/config.env.example \
   ~/.claude/skills/seo-article-writer/config.env

# Заполни config.env своими данными (API ключи, SSH доступ, пути)
```

**Шаг 2: Подключи первый проект**

Запусти Claude Code и скажи:
```
/seo-article-writer добавь продукт myproduct.ru
```

Скилл автоматически:
- Просканирует сайт
- Соберёт информацию о продукте
- Создаст профиль продукта
- Создаст площадку для публикации (если нужна)

**Шаг 3: Напиши первую статью**

```
/seo-article-writer напиши SEO-статью для Дзен на тему: лучшие инструменты для [ваша ниша]
```

Подробности установки и настройки — в [INSTALL.md](INSTALL.md).

## Как работает: 10 этапов пайплайна

```
ТЕМА СТАТЬИ
     |
     v
[1] Сбор семантики (Wordstat MCP)
     |  - маркерные запросы
     |  - частотность, LSI, сезонность
     |  - целевой запрос + кластер
     v
[2] Анализ конкурентов (WebSearch + WebFetch)
     |  - топ-5 результатов поиска
     |  - структура, интент, гэпы
     |  - матрица Content Gap
     v
[2.5] Сбор фактуры (WebFetch первоисточников)
     |  - цены с /pricing
     |  - статистика из отчётов
     |  - реестр проверенных фактов
     v
[3] Планирование изображений
     |  - обложка, скриншоты, иллюстрации
     |  - карта: что, где, какой тип
     v
[4] Разработка структуры
     |  - H1/H2/H3 скелет
     |  - формат (гайд/обзор/рейтинг/FAQ)
     v
[5] Генерация изображений
     |  - обложка через Nano Banana 2
     |  - скриншоты через Playwright
     |  - AI-иллюстрации к разделам
     |  - проверка качества каждого изображения
     v
[6] Написание статьи
     |  - под YATI (Яндекс) + E-E-A-T (Google)
     |  - min 2500 слов, 1 картинка / 300-400 слов
     |  - вставка изображений в текст
     v
[7] On-page оптимизация
     |  - Title, Description, Schema.org
     |  - OpenGraph, перелинковка
     v
[8] Финальная проверка качества
     |  - визуальная проверка ВСЕХ изображений
     |  - проверка ссылок, семантики, фактуры
     |  - 8 категорий чек-листов
     v
[9] Сравнение с конкурентами
     |  - наша статья vs. топ-3
     |  - по всем параметрам должна быть лучше
     v
[10] Публикация
     |  - ПУТЬ 1: WordPress API -> RSS -> Дзен
     |  - ПУТЬ 2: HTML-файл для копипаста
     |  - ПУТЬ 3: Prisma Blog API (MDX)
     v
СТАТЬЯ В ТОПЕ
```

## MCP-интеграции

- **Wordstat MCP** — сбор семантики из Яндекс Wordstat (частотность, вложенные запросы, LSI, сезонность, география)
- **SerpAPI MCP** — поиск конкурентов в выдаче (опционально)
- **WebFetch/WebSearch** — анализ конкурентов, проверка фактуры
