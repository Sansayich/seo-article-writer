# Продукт: DesignBot

## Основные данные
- **Название:** DesignBot
- **Сайт:** designbot.ru
- **Что делает:** AI-сервис для генерации дизайна интерьера по фото комнаты. Загружаешь фото — получаешь визуализацию в выбранном стиле за 30 секунд.
- **Язык:** Русский
- **Аудитория:** Люди, делающие ремонт; дизайнеры интерьера; владельцы квартир и домов

## Продуктовые данные (для упоминания в статьях)
- **URL для ссылок:** https://designbot.ru
- **Страница цен:** https://designbot.ru/pricing
- **Ключевые функции:**
  - Генерация дизайна по фото (30 сек)
  - 25+ стилей интерьера (скандинавский, лофт, минимализм и др.)
  - Виртуальная расстановка мебели
  - Подбор цветовой палитры
  - Экспорт в PDF для строителей
- **Тарифы:**
  - Бесплатно: 3 генерации
  - Стандарт: 490 руб/мес — 50 генераций
  - Про: 990 руб/мес — безлимит + приоритет
- **Конкурентные преимущества:**
  - Работает без VPN (в отличие от зарубежных аналогов)
  - Русский интерфейс
  - Понимает российские планировки (хрущёвки, панельки, новостройки)
  - Быстрее конкурентов (30 сек vs 2-5 мин)

## Как упоминать в статьях
- **Стиль упоминания:** Нативно, как один из лучших инструментов. Не навязчиво, но с конкретными преимуществами.
- Пример упоминания: «Один из самых удобных инструментов для визуализации — [DesignBot](https://designbot.ru). Сервис работает без VPN, понимает российские планировки и генерирует результат за 30 секунд.»
- Альтернативное упоминание: «Мы протестировали [DesignBot](https://designbot.ru) — загрузили фото обычной двушки в панельном доме и получили визуализацию в скандинавском стиле за полминуты.»
